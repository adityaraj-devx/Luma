# LUMA

LUMA is a simple, modern, and responsive multi-page website built using HTML and CSS.

## 🎯 Purpose

This project was created for **skill development and web development practice**.

The main goal was to improve my practical understanding of HTML, CSS, responsive design, layouts, and building a complete website from scratch.

## 📌 Pages

- **Home** – Introduction and overview of LUMA
- **About** – Company story, process, and team
- **Services** – Services and working process
- **Contact** – Contact information and contact form

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome
- Google Fonts

## ✨ Features

- Responsive design
- Multi-page website
- Modern and minimal UI
- Responsive navigation
- Service cards
- Team section
- Contact form
- Font Awesome icons
- Mobile-friendly layout

## 🚀 How to Run

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

You can also use the **Live Server** extension in VS Code for easier development.

## 📱 Responsive Design

The website is designed to work on:

- Desktop
- Laptop
- Tablet
- Mobile
